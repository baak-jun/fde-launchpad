# {{PROJECT}} 인수인계

## 목적과 사용자

- 해결할 업무 / 사용자 / 성공 조건: BRIEF.md를 채운다.
- 원본 키트에서 새로 복사한 소스다. 이 복사본의 실행 검증은 아직 하지 않았다.
- evidence/에 동봉된 기록은 원본 키트의 증거다. 새 환경에서 verify.py를 실행해 이 복사본의 기록을 갱신한다.
- 현재 기본 동작: 규칙 기반 초안과 로컬 기록. 외부 발송·결제는 없다.

## 먼저 실행

```powershell
./scripts/setup.ps1
.venv/Scripts/python.exe scripts/doctor.py
.venv/Scripts/python.exe scripts/verify.py
.venv/Scripts/python.exe run_workbench.py
```

브라우저: http://127.0.0.1:8765 . 해당 포트가 다른 프로젝트에 사용 중이면 `--port 8766`을 사용한다.

## 다음 세션에 남길 사실

- 마지막 실제 성공 명령과 날짜: 미실행
- 변경 파일 / 이유 / 해당 요구사항: 미작성
- 실패한 검증 / 재현 입력 / 오류: 미확인
- 살아 있는 프로세스와 포트: 새 세션에서 확인
- 모델 모드·외부 연결·비용 상태: 기본 rules, 외부 미연결
- 소스와 DB 백업 경로·해시: 복사본에서 새로 생성
- 다음 한 작업과 완료 조건: BRIEF.md를 채우고 검증을 실행
- 사용자가 판단해야 할 사항: 실제 도메인 규칙, 데이터, 실제 모델/외부 연동 범위

키·계정 값·민감 데이터는 이 문서에 넣지 않는다. 이전 세션의 프로세스 번호를 현재 살아 있다는 증거로 사용하지 않는다.
