# 내가 직접 설명하는 결과물

코드를 보지 않고 먼저 답한 뒤, 실제 함수와 테스트를 열어 확인한다. 아래 질문에 AI가 써 준 답을 읽는 것만으로 본인의 이해가 검증되지는 않는다.

1. 사용자 입력 하나가 어떤 파일·함수를 거쳐 저장되는가?
2. 모델 출력이 형식은 맞지만 사실이 틀리면 어디에서 걸러지는가? 못 거르는 경우는?
3. 승인한 뒤 입력이 달라지면 기존 승인이 왜 무효가 되는가?
4. 실행 버튼을 두 번 누르거나 프로세스를 다시 켜면 어떤 결과가 남는가?
5. 도메인을 바꿀 때 바꿀 파일과 그대로 둘 파일은?
6. 이 레포·라이브러리를 선택한 이유와 포기한 대안은?
7. 실제 AI, 규칙, 테스트용 모델, 모의 외부 작업은 각각 어디인가?
8. 가장 위험한 가정 세 가지와 깨뜨릴 입력은?
9. 통과한 테스트가 증명하지 않는 것은?
10. 다른 사람이 15분 안에 이어서 하려면 무엇이 필요한가?
