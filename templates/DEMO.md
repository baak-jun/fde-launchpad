# 3분 데모 시나리오

1. 0:00–0:25: 누가 어떤 반복 업무로 불편한지 실제 사례 하나를 제시한다.
2. 0:25–1:30: 입력 → AI 처리 → 근거/검증 → 사용자 확인 → 결과를 보여준다.
3. 1:30–2:00: 잘못된 입력 또는 근거 없는 질문에서 보류·복구하는 모습을 보여준다.
4. 2:00–2:35: AI 없는 기준선 대비 시간·정확도·비용의 실제 측정값을 비교한다.
5. 2:35–3:00: 재사용한 오픈소스와 직접 만든 도메인 기능, 다음 적용 대상을 설명한다.
