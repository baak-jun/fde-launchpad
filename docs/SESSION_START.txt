이 폴더의 범용 FDE 키트를 이어서 작업해줘.

먼저 HANDOFF.md, README.md, docs/VALIDATION.md와 현재 파일·Git 상태를 확인해.
기존 대화의 완료 주장보다 현재 소스와 실행 증거를 우선해.
전체 개선 전에는 scripts/checkpoint.py로 백업하고, DB가 있으면 scripts/backup_data.py도 실행해.
현재 사용자가 해결하려는 문제를 BRIEF.md와 INTENT.md로 구체화하고 기존 레포와 모듈을 재사용해.
모델·외부 시스템·네이티브 장치의 미검증 영역을 이미 동작하는 것으로 가정하지 마.
변경 후 관련 검증과 전체 흐름을 확인하고, 무엇을 왜 바꿨는지와 다음 작업을 HANDOFF.md에 남겨.
마지막 설명은 비전문가가 읽어도 이해할 수 있게 결과·사용법·근거·한계를 연결해줘.
