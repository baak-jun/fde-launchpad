# 화면으로 비교하는 디자인 라이브러리 v2

[새 갤러리](index.html) · [기존 토큰 갤러리](token-gallery.html)

기존의 토큰·색상표 중심 12종에, 서로 다른 화면 구조를 보여주는 12종을 추가했다. 총 24종의 DESIGN.md를 보관한다. 첫 화면에서는 브랜드 이름보다 사용자 흐름과 레이아웃의 차이를 먼저 비교한다.

## 직접 조사한 두 사이트

- [getdesign.kr](https://www.getdesign.kr/) → [CaesiumY/ko-design-md](https://github.com/CaesiumY/ko-design-md). 한국 서비스 디자인 분석과 재현 HTML을 공개한다. 이번에는 8개 MD 원문과 화면 예시를 보관했다.
- [getdesign.md](https://getdesign.md/) → [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md). 공개 GitHub에서 Oura, WIRED, Dell 1996, Nintendo 2001의 MD 원문을 가져왔다. 사이트의 기본 프리뷰도 토큰 표 중심이라, 각 MD를 참고한 새로운 정적 응용 시안을 별도로 만들었다. 유료 카탈로그·스타터 키트를 구매하거나 제한된 자료에 접근하지 않았다.

확인일은 2026-10-26. 원본 MD는 그대로 저장했다. 원본 내 추정치·Known Gaps·근거 링크는 적용 전에 읽는다.

## 이미지와 구현 범위

각 `screens/이름/`에 DESIGN.md, APPLY.md, PROMPT.txt, screen.html, screenshot.png가 있다. 한국 자료에는 수정 전 UPSTREAM.html과 스크립트를 제거한 전체 preview.html도 보존한다.

스크린샷은 이번 작업에서 로컬 HTML을 실제 브라우저로 렌더링해 캡처했다. 공식 서비스의 실제 사용자 화면은 아니다. 리디·직방·NOL 등 일부 원본 예시는 사진·표지·지도 내용을 자리표시자로 남긴 구조 시안이다. 신규 해외 시안의 그림은 로컬 CSS 도형이며 실제 제품 사진이 아니다. 모든 사례는 시각 참고용 정적 화면이며 금융·채용·예약 기능을 실행하지 않는다.

한국 원본 수정: 화면 구역 선택, 실행 스크립트·인라인 이벤트 제거, 에셋 경로 변경, 출처 표시 추가, SVG 정의를 숨김 영역에 보존. 원본에 포함된 웹 폰트는 온라인에서 요청될 수 있고 오프라인에서는 폰트가 달라질 수 있다. 저장된 PNG는 인터넷 없이 확인할 수 있다.

## 다음 프로젝트에서 쓰기
